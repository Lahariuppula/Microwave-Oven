# Microwave Oven Controller Using Embedded C

## Description
An embedded C project that simulates the control logic of a microwave oven using a PIC microcontroller. The system uses a matrix keypad for user input and a character LCD (CLCD) to display operating modes, cooking time, temperature, and preheating status.

## Features
- Display a power-on animation and menu screen.
- Select microwave, grill, and convection modes.
- Display the power rating.
- Set cooking time using a matrix keypad.
- Set temperature with a maximum limit of 180°C.
- Start, pause, resume, and stop the cooking timer.
- Support a preheating countdown.
- Activate a buzzer when the cooking timer finishes.
- Control a cooler output during cooking.
- Use Timer2 interrupts for timekeeping.

## Technologies Used
- **Programming Language:** Embedded C
- **Microcontroller:** PIC16F877A
- **IDE:** MPLAB X IDE
- **Compiler:** XC8
- **Peripherals:** Matrix Keypad, Character LCD, Timer2, Buzzer, Cooler Output
- **Concepts:** Interrupts, Timers, GPIO, State Machines, Embedded C Programming

## Project Structure
- `main.c` – Main application loop and screen-state management.
- `main.h` – State definitions, macros, and shared declarations.
- `microwave.c`, `microwave.h` – LCD screens and microwave interface functions.
- `matrix_keypad.c`, `matrix_keypad.h` – Matrix keypad initialization and scanning.
- `clcd.c`, `clcd.h` – Character LCD initialization and display functions.
- `timers.c`, `timers.h` – Timer2 initialization.
- `isr.c` – Timer2 interrupt service routine for countdown timing.
- `Makefile` – Build configuration generated by MPLAB X IDE.

## How It Works
1. The system initializes the LCD, keypad, Timer2, and output pins.
2. The LCD displays the power-on animation and main menu.
3. The user selects an operating mode and configures cooking time or temperature.
4. The timer interrupt updates the countdown.
5. The user can start, pause, resume, or stop the cooking operation.
6. When the countdown reaches zero, the system stops the cooler and activates the buzzer.

## Build and Run
1. Open the `MicrowaveOven.X` project in MPLAB X IDE.
2. Configure the project for the target PIC microcontroller and XC8 compiler.
3. Build the project to generate the HEX file.
4. Program the HEX file onto the microcontroller using a compatible programmer.
5. Connect the LCD, keypad, buzzer, and cooler-control circuit according to the project pin configuration.

## Concepts Learned
- Embedded C programming for PIC microcontrollers.
- Matrix keypad scanning and debouncing.
- Character LCD interfacing in 4-bit mode.
